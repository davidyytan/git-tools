Title guidance:
- The Pull Request title is fixed for this mode.
- Use exactly `## Title: {fixed_title}` in the output.
- Do not generate an alternative title or vary the title wording.
- Use this mode for hotfix backmerge PRs from `hotfix/*` to `develop`.
- Frame the PR as syncing hotfix fixes back into `develop`.
- Good examples: `Backmerge Hotfix 1.6.1`, `Backmerge Hotfix 1.6.2`, `Backmerge Hotfix 2.0.1`.
- In the body, make it clear that if `develop` is already ahead it keeps that line and meaningful unique fixes may advance alpha by one there.
- If `develop` is not ahead yet, make it clear that the backmerge may catch `develop` up to the target stable version without tagging.
- Do not invent QA results, rollout steps, or release notes not supported by the available artifacts.
